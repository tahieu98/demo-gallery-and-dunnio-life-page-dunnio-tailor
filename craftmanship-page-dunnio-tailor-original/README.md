# craftmanship-page-dunnio-tailor-original

Original reference of https://dunniotailor.com/our-tailors, captured on 15 November 2026 (Asia/Bangkok).

Open `index.html` directly, or run `npm start` from the parent repository. This is a static HTML/CSS/JavaScript reference with source layout, three profiles, navigation, language destinations, contact links, footer disclosure and local email validation. Profile links open full locally stored prose in an accessible dialog; the original source URL remains available in each profile. Live account, checkout, ordering, contact and translation destinations open their real websites.

`source-0.css` through `source-2.css` and the inline critical CSS preserve the captured source styling. `reference.css` and `reference.js` implement local interactions without Drupal, analytics or server form submissions. Assets and profile prose are in the sibling `craftmanship-page-dunnio-tailor-assets/` directory, which must travel with this folder. No PDF originals or internal research files are published.

See [Order 5 design, structure and sources](../docs/order-5-design.md) and [verification](../docs/order-5-verification.md). The `craftmanship` spelling in directory names follows the user's requested naming; visible English copy uses `Craftsmanship`.
